# ArchiveWorker / 档案净页

面向内网档案扫描图的离线 WPF 批量清理工具。当前 MVP 已接入真实 OpenCV 四边缺陷检测、内容保护、局部背景修复、人工复核和安全批量输出。

## 运行

```powershell
dotnet run --project .\ArchiveCleaner.Wpf\ArchiveCleaner.Wpf.csproj
```

发布级构建与测试：

```powershell
dotnet build .\ArchiveWorker.sln -c Release
dotnet test .\ArchiveWorker.sln -c Release
```

## 当前功能

- 加载单张或递归扫描多层目录中的 JPG、PNG、TIFF、BMP，并支持扫描型 PDF；PDF 在树中显示为虚拟文件夹，下面按页显示图片节点，每页独立分析、复核和修复，导出时重新组装为一个 PDF；树节点默认全选并支持目录三级联动，分析、批量确认去除和导出只处理已勾选页面；目录菜单支持全选、全不选、展开、折叠、移除已勾选项和清空队列，且不会删除源文件
- 按四边独立开关和毫米范围生成候选区域，检测黑边、阴影、装订孔和局部污渍
- 提供快捷总灵敏度及可折叠高级检测参数，可分别调整浅痕、深色区域、小缺陷、断裂连接、边影追踪和自动清除门槛；像素参数按图片 DPI 归一化
- 在批次第一遍检测后按归一化位置和形状关联重复缺陷，只提高相似痕迹置信度且不绕过内容保护
- 使用保守的 OpenCV 规则保护正文、手写、印章、表格线和页码，冲突区域标为黄色待复核
- 显示真实红色自动清理、绿色内容保护和黄色待复核掩膜
- 支持逐区域“保留”或“确认去除”，未确认的冲突不参与修复
- 支持在风险面板中一次批准去除批次内所有未确认的黄色区域；已明确保留的区域不会被覆盖
- 支持可调大小的圆形保护笔刷、去除笔刷、恢复橡皮擦和保护矩形；恢复橡皮擦可恢复自动去除、已确认去除及人工去除区域中的原图内容；每种工具可从六种预设颜色中独立选择，恢复橡皮擦默认使用灰色；人工保护优先于人工去除，并可按图片撤销或重做最近 100 次编辑
- 预览支持适合窗口及 25%～400% 缩放，并提供同步滚动的并排视图、可拖动分界线的滑块对比和深色背景的纯掩膜视图
- 使用局部背景采样或 OpenCV inpaint 生成修复预览，羽化参数参与融合
- 提供“仿制图章修复”和“污点修复”两种局部纹理模式：自动排除保护区域后寻找附近干净源块，对污点做亮度和纹理融合；找不到可靠源块时回退到 Inpaint
- 批量写入新目录并保留源目录的相对层级，避免不同子目录同名图片互相覆盖；保留尺寸和 DPI，支持进度、取消、单页错误隔离与原子提交
- 批量导出只生成处理后的图片，不附带审计报告或其他额外文件
- 加载或保存当前参数为 JSON 方案，全部高级参数进入审计设置快照，始终不覆盖源图
- 程序正常关闭时自动保存处理参数到 `%LocalAppData%\\ArchiveCleaner\\settings.json`，下次启动自动加载；配置损坏时回退系统默认值。处理设置页面底部可用“恢复默认参数”一次恢复全部系统默认值
- “取消任务”只在分析、预览、批量确认或导出运行期间启用，取消不会修改源图片，已完成提交的结果会保留

界面顶部的“分析当前批次”只生成预览；右侧的“导出结果”会重新分析、修复并写出图片。未先分析时，导出会自动补做分析。

## 实现边界

PDF 支持面向扫描型、图像型 PDF：页面会按 300 DPI 栅格化后复用图片清理流程，输出为图像型 PDF。带文字层、表单、批注、签名、嵌入文件或加密的复杂 PDF 当前不会保留原生对象；选中的页面处理失败时不会提交该 PDF 的最终输出并报告错误，未选中的页面会原样保留在输出 PDF 中。

当前未接入 ONNX 内容检测模型：仓库中没有来源、许可证和输入输出规约均可验证的离线模型。程序会明确回退到 OpenCV 保守规则；传统规则无法 100% 区分黑色手写笔画与黑色污渍，因此冲突区域默认留待人工确认。
